How do I get paid?

To get paid for running integration tests, you need to trust the hX asset HEXA. This page prepares and runs the corresponding hX transaction for you, which you need to sign with your account's secret key - a 56 character string that starts with 'S'. Copy and paste it into the input field below.

How do I make sure my account will not be compromized?

Your secret key value never appears on this page and isn't stored anywhere. It is passed to hX changeTrust transaction - view the page source and see for yourself.
