How do I get paid?

To get paid for running integration tests, you need to trust the hX asset HEXA. This page prepares and runs the corresponding Stellar transaction for you. You do not pay for this transaction to run (we do), all you need to do is to sign it with your account's secret key - a 56 character string that starts with 'S'. Copy and paste it into the input field below.

How do I make sure my account will not be compromized?

Your secret key value never appears on this page. It is only used inside your javascript function called prepareAndSignStellarTx. View the page source and see for yourself.
