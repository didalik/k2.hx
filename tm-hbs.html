This page outlines the way I code and debug cloud-based apps. It runs integration tests for my hobby projects:
  • Stellar Help Exchange;
  • Stellar TESTNET Monitor; and
  • Cloudflare Job Fair.

Stellar Help Exchange (hX) is an equitable global marketplace - if you don't get the help you paid for, you get your payment back. Stellar TESTNET Monitor (TM) queues hX demo requests (demos can't run in parallel) and pairs you with a jF demo agent when your demo request is granted. Cloudflare Job Fair (jF) serverlessly binds Job Users like you with Job Agents. And yes, the hX demo is a jF Job.

See also console.log for this page and the code located at my k2.hx and k2.jf GitHub repos.
